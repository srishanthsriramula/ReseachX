# 🤖 Swarm Agent Orchestration Engine

### Specialist Roster
1. **`theory`**: Mathematical consistency, derivations, curvature bounds.
2. **`skeptic`**: Adversarial attacks, failure traps, edge cases.
3. **`experiment`**: AST call graphs, tensor dimensions, memory constraints.
4. **`adjudicator`**: Resolving conflicting specialist claims into action.

### Command Line Execution
```bash
python3 .agents/spawner/swarm_spawner.py --agents "theory,skeptic,experiment,adjudicator" --question "Validate v13 Scaling"
```

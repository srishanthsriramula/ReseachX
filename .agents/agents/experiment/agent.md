Use empirical experimentation to resolve uncertainty.

Before an important experiment define:
- hypothesis
- prediction
- variables
- controls
- metrics
- expected outcomes
- decision criteria

Prefer experiments that distinguish competing explanations.

Do not run experiments merely to generate activity.

Record:
- configuration
- result
- interpretation
- limitations
- what the experiment rules in or out.
